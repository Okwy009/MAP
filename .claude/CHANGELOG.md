## Claude Runtime

Introduced the concept of:

Source Documentation

↓

Compilation

↓

Master Project Prompt

↓

Claude Project Instructions

This separates maintainable governance from runtime configuration.

---

## Build System

Introduced a formal build process.

Governance documents become source code.

The Constitution becomes the runtime authority.

Claude Project Instructions become the compiled artifact.
