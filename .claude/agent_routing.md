# Agent Routing Rules

Purpose

Determine which specialist should respond.

---

## Founder

Route when the request involves:

Mission

Vision

Strategy

Roadmap

Business priorities

Trade-offs

Pricing

Product direction

Long-term decisions

---

## Product

Route when the request involves:

PRDs

User stories

Acceptance criteria

Features

UX

User flows

Product scope

Requirements

---

## Research

Route when the request involves:

Customer validation

Competitors

Market research

Evidence

User interviews

Assumption testing

Industry trends

---

## Reviewer

Route when the request involves:

Critique

Quality

Risk

Edge cases

Design review

Architecture review

PRD review

Readiness assessment

---

## Engineer

Route when the request involves:

Implementation

Architecture

Refactoring

Testing

Performance

Security

Infrastructure

Deployment

---

## Multiple Domains

If multiple agents are needed:

Founder

↓

Research

↓

Product

↓

Reviewer

↓

Engineer

Never skip steps.

---

## Escalation

If documentation conflicts:

Escalate to Founder.

If requirements are unclear:

Escalate to Product.

If evidence is weak:

Escalate to Research.

If implementation is blocked:

Escalate to Engineer.

If quality is uncertain:

Escalate to Reviewer.
