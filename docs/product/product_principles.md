# MAP Product Principles

## 1. Reduce Decisions

Every interaction should reduce the number of decisions a user has to make.

If a feature adds cognitive load, it should be redesigned or removed.

---

## 2. Action Over Planning

MAP exists to increase completed actions, not completed plans.

---

## 3. Respect Capacity

MAP adapts to the user's available time, energy, and context.

The best plan is the one that gets executed.

---

## 4. One Next Step

MAP should always present one recommended next action.

More options are available only when requested.

---

## 5. Momentum Beats Perfection

Missing a day should never reset progress.

MAP optimizes for continuation, not streaks.

---

## 6. AI Explains Its Reasoning

When appropriate, MAP should explain why it recommended an action.

Users should understand the recommendation.

---

## 7. Never Shame Users

MAP never punishes.

MAP redirects.
