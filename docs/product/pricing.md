Pricing Philosophy

# Pricing Philosophy

MAP is not priced as a tool.

It is priced as a system that helps you not lose momentum — and each paid tier
unlocks the next stage of that system, in the order the system actually needs
to work: plan first, then track, then adapt, then distribute.

# The MAP Experience — 4 Stages

## Stage 1 — Free — $0/mo
**MAP Dashboard + 30-Day Plan**
- Deterministic next-step generation (rules-based, per AD-007)
- Daily usage
- No context memory across sessions

## Stage 2 — Starter — $19/mo
**+ Engagement Tracker**
- Everything in Free
- Completion tracking (streaks, consistency)
- Input tracking (ideas, reading, inspiration)
- Weekly review summaries

## Stage 3 — Pro — $49/mo
**+ AI Approach**
- Everything in Starter
- Adaptive recommendations, powered by the execution history Starter builds
  (per AD-007: AI is introduced only once there's real history to learn from)
- Full context awareness (goals, history)
- Publishing-focused workflows

## Stage 4 — Creator+ — $99/mo
**+ Multi-Platform Distribution**
- Everything in Pro
- The same underlying plan/content adapted and distributed across multiple
  platforms (Substack, Instagram, TikTok, and others)
- Advanced personalization
- Accountability loops

# Pricing Principle

Users are not paying for AI. They are paying for reduced cognitive load and
consistent execution — and each tier is a deeper commitment to that outcome,
not just a bigger feature list.

# Upgrade Flow

Free is the default state for every new signup — no paywall blocks initial
access. The upgrade prompt is introduced contextually, after the creator has
completed Onboarding (MAP-004) and experienced real value (their first
generated plan/action) — not immediately after signup.

# Architecture Note (not yet built)

Stage 4's multi-platform distribution requires a new system component not
currently defined in system_architecture.md — tentatively a "Distribution
Service," responsible for adapting one piece of content/plan output into
platform-specific formats. This is meaningfully more AI-dependent than
Stage 3's recommendations (true content adaptation, not just reposting) and
should be scoped as its own PRD once Stages 1-3 are built and validated.
