How MAP Works (Core System)

MAP operates on a simple loop:

1. Input State

User provides (explicitly or inferred):

Goal (what they want to achieve)
Available time (5 min, 30 min, 2 hrs)
Energy level (low / medium / high)
Context (where they are in their workflow)
2. Decomposition Engine

MAP breaks the goal into:

smallest possible meaningful actions
actions that can be completed in current constraints
3. Filtering Logic

MAP removes:

high cognitive load tasks
multi-step planning
ambiguous actions
perfection-heavy outputs

It prioritizes:

clarity
immediacy
completion probability
4. Output

MAP returns:

One next step that is:

small enough to start immediately
meaningful enough to maintain progress
simple enough to avoid overthinking
Key Principle

MAP does NOT optimize for best possible action.

It optimizes for:

action that will actually be done today
