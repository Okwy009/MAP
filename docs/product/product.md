What MAP Is

MAP is a decision-reduction system for daily execution.

It converts a user’s:

goal
available time
energy level
current context

into a single actionable next step.

What MAP Is NOT
Not a habit tracker
Not a productivity dashboard
Not a generic AI chat assistant
Not a project management tool
Core Output

MAP always produces:

One clear next action the user can complete now

Optionally:

2–3 alternatives if needed
time estimate
difficulty level
