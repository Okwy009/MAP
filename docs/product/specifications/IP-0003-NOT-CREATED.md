## Why no IP-0003 exists

Per AD-009 ("Documentation Before Code"), an Implementation Package is only
written after its corresponding PRD is **approved**. PRD-0003 (Landing Page)
was drafted, but never reached Approved status — it was closed instead, once
the auth-aware homepage fix (app/page.tsx, shipped 2026-09-12) resolved the
underlying problem PRD-0003 was written to solve.

Since PRD-0003 never cleared the approval gate, no Implementation Package was
ever required or written. This file exists solely so the PRD/IP numbering
sequence has no unexplained gap — a future reader checking
`docs/product/specifications/` for IP-0003 will find this note rather than
wondering if a document was lost.
